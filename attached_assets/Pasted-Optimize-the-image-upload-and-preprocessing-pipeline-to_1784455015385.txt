Optimize the image upload and preprocessing pipeline to improve editing performance on lower-end devices without changing the existing editing experience. Context Painting and editing become noticeably laggy on larger images when tested on a Samsung Galaxy J7 (2016). This is an old, low-end device, so the goal is not to reduce quality for everyone, but to intelligently choose an appropriate default image size based on the user's device capabilities. The application already supports resizing uploaded images manually. That functionality must remain unchanged. Goal Before an image enters the editor, automatically choose one of the following maximum long-side resolutions: 2048 px (Maximum Quality) 1440 px (High Quality) 1080 px (Medium Quality) 720 px (Low Quality) The selection must happen automatically without any user interaction. Requirements Detect device capability using available browser APIs and performance heuristics (for example navigator.deviceMemory, navigator.hardwareConcurrency, browser support, and lightweight runtime performance tests if appropriate). Choose the most suitable default resolution based on the detected device. Prefer actual performance measurements over assumptions whenever practical. Do not rely on user-agent detection alone. Keep the detection lightweight so startup is not noticeably slower. The decision should occur before the image is loaded into the editor. User Experience Users should never be asked to choose a quality level. The application should quietly select the best default resolution so that editing feels smooth on their device. If the user later chooses to manually increase the image size using the existing resize controls, that behavior must continue to work exactly as it does today. Automatic resizing is only the initial default. Important Do not remove or modify the existing manual resize feature. Do not regress any existing painting or object editing functionality. Preserve image quality as much as possible while prioritizing a smooth editing experience. Ensure the implementation is maintainable and easy to adjust if the resolution thresholds need tuning in the future.
