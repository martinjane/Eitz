I have a few more changes. First, make all text in the Guide page unselectable, just like the text on the Home page. Also, I want advertisements to be handled similarly to owned channels. Advertisements should be created and verified beforehand, just like owned channels, and they should have their own section in Settings. Make the part where users upload an advertisement image and write the advertisement text accessible from Settings under an Add Advertisement section. Advertisements should still go through the same verification process they currently have. I only want to change when they are created, not how they are verified. Just like before, when creating an advertisement, the user should still select the channel the advertisement belongs to. Then, instead of having users upload the image and write the text every time they go through the advertisement flow, the advertisement pages should simply let users select one of their previously created advertisements, then choose the date and time slot for it. The idea is to separate advertisement creation from advertisement scheduling, just like owned channels are managed separately from where they are used. Also, in Settings, add an option that lets users cancel any pending verification requests for both advertisement verification and channel ownership claims. Finally, I want users to be able to make specific parts of their advertisement text bold while writing it. Add support for this in the advertisement text editor, and place a small note near the text input explaining how to use the bold formatting. Also, improve the pinch-to-resize behavior for text objects in the image editor. If the user is dragging a text object with one finger and then places a second finger on the screen without lifting the first one, the interaction should smoothly transition into pinch-to-resize. The text should resize continuously in real time while staying at its current position. It should not snap back to the position where it was first touched before the pinch began. The transition between dragging and pinching should feel smooth and natural. If any other part of the app follows a different or less smooth pinch-to-resize behavior, update it to match this same interaction so resizing feels consistent throughout the app.
