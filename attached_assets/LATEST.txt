Donation Default Advertisement Improvements

The donation default advertisement needs several improvements:

The donation advertisement icon is incorrect. Replace it with a heart icon.

The green color currently used does not match the app theme. Update it so it follows the application's theme styling.

The donation advertisement text is too short.

Improve the donation advertisement content structure:

Show a short, suitable first message that fits naturally in the advertisement card.

Allow users to expand it to see a longer explanation about why donations are needed and what they support.

Keep the design clean and avoid making the advertisement overwhelming.

Donation Advertisement Notification Behaviour

Clicking the donation advertisement notification currently does nothing.
Fix this so:

Clicking the donation advertisement notification takes the user to the donation page.

Also, add protection against accidental loss of user work:
If the user clicks a built-in/default advertisement notification while they are working in the app (for example, editing an image before saving), do not immediately redirect them.
Instead, for built-in/default advertisements only:

Show a confirmation dialog before leaving the current page.

The dialog should ask whether the user wants to continue to the advertisement destination or stay on the current page.

Important:

This confirmation should only apply to built-in/default advertisements managed by the app.

Do not apply this confirmation to user-submitted advertisements.

Be careful with the wording so it does not discourage users from opening advertisements when they genuinely want to. The purpose is only to prevent accidental loss of work.

Normal image editor.

Studio editor.

Saved Styles editor.

Verify the behaviour works consistently in all three locations.

Bug Reporting and Feedback System

Add a simple bug reporting and feedback feature.
Requirements:

Add a small visible section on the Home page where users can submit feedback or bug reports.

Users can write up to 200 characters.

No user identity needs to be stored with the report.

Each user can submit only one bug report or feedback message every 5 days.
